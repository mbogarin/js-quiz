## Project Description

This project is an interactive quiz that presents users with multiple-choice Formula 1 questions. Users select answers, receive visual feedback, and see their final score at the end of the quiz.

The quiz includes:

- A start screen
- A sequence of randomized questions
- Progress tracking
- A score summary
- The ability to restart the quiz

This project was built as part of practicing JavaScript fundamentals and frontend development concepts.

## Features

- 🏁 Start quiz screen
- ❓ Multiple choice questions
- 🔀 Randomized question order
- 📊 Question progress display
- ✅ Instant correct/incorrect feedback
- 🧮 Score calculation
- 🎯 Final score screen with message
- 🔁 Restart quiz functionality

## Installation

- Instructions

1. Clone this repository

    ```bash
    git clone git clone https://github.com/mbogarin/js-quiz.git
    ```

2. Navigate into the project folder

    ```bash
    cd js-quiz
    ```

3. Open the project folder in your code editor and launch the `index.html` file in your browser.

## Usage

-   1. Open the quiz in a browser.
-   2. Click Start Quiz.
-   3. Select an answer for each question.
-   4. Click Next Question to continue.
-   5. At the end of the quiz, view your score and performance message
-   6. Click Restart Quiz to try again.
